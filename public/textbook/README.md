# Reference textbook

The study app uses one permanent reference textbook at:

`public/textbook/Power-Engineering-Fourth-Class-Part-A-Edition-3.5.pdf`

The expected source is **Power Engineering, Fourth Class, Edition 3.5, Part A**.

Users of the app do not upload their own textbook. Source-page links, the textbook viewer, formulas, lessons, and textbook self tests all refer back to this fixed reference copy.
